# Settings & Themes

The settings drawer has been reorganized into a more practical structure in Runicorn 0.7.0.

---

## Appearance

Important controls include:

- theme mode: light, dark, auto
- accent color
- density
- background type
- surface colors

The current UI also adds multiple theme presets and more control over panel surfaces.

---

## Why surface colors matter

Surface color lets you tune the panel background separately from the page background, which is useful when you want a more neutral or more glass-like look without hurting readability.

---

## Compare and chart settings

Settings now cover:

- chart height
- max data points
- animation preferences
- compare tooltip preferences

---

## Storage and alerts

Other settings sections now include:

- storage root controls
- dismissed alerts
- GPU collector options

---

## Current design direction

Compared with the older UI, Runicorn 0.7.0 favors:

- more professional defaults
- less decorative motion
- better dark-mode consistency
- better readability for long sessions
