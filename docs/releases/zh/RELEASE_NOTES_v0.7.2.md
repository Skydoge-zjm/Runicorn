# v0.7.2 发布说明

**发布日期**: 2026-05-11

---

## 概览

Runicorn v0.7.2 是紧跟 v0.7.1 发布后的补丁版本。它不引入新的产品表面，而是修复发版后暴露出来的打包、CI、依赖元数据和跨平台测试问题。

---

## 重点

### 打包与发布流程修复

- 发布脚本改为使用统一版本源，不再依赖旧的 `pyproject.toml` 版本字段
- 按当前 `runicorn_dev` 环境和现有构建后端重新验证发布链路

### CI 与依赖修复

- 修复 CLI 导出路径中缺失的 `Path` 导入
- 为 Python client 补齐缺失的 `requests` 运行时依赖声明
- 为 client 工具测试补齐缺失的 `pandas` 开发依赖声明

### 跨平台测试修复

- OpenSSH askpass 测试更新为同时兼容 Windows 和非 Windows 的包装脚本命名
- 修复 v0.7.1 发布后出现的 CI 红灯问题，使当前流水线重新回到绿色

---

## 与 v0.7.1 的关系

如果你关注这一轮版本线里的主要用户可见变化，请优先阅读 [RELEASE_NOTES_v0.7.1.md](RELEASE_NOTES_v0.7.1.md)。v0.7.2 是它的后续补丁版本，重点在于把已经发布出去的 0.7.1 包和发布链路收稳。
