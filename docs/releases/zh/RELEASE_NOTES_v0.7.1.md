# v0.7.1 发布说明

**发布日期**: 2026-05-10

---

## 概览

Runicorn v0.7.1 是在 v0.7.0 基础上的稳定化版本。本次发布重点不在新增产品能力，而在于收紧可靠性、安全边界、发布元数据和桌面构建可复现性。

---

## 亮点

### 稳定性与 API 对齐

- 收紧 metrics 写入 identity 处理，避免旧 schema 路径下的覆盖风险
- 围绕当前统一 Remote Viewer 模型清理 Remote API 表面
- 远程 API 与架构文档重新对齐到实际已发布的路由和 session 状态

### 安全与兼容性

- 收紧历史 XOR 凭据迁移边界
- 已保存凭据兼容链路更清晰，也更稳妥

### 测试与 CI 加固

- 扩充前端 loading / baseline / smoke 覆盖
- 针对当前前端与桌面构建表面补强 CI 验证

### 桌面构建加固

- 引入分层 desktop build 配置
- sidecar 打包流程更可复现
- 补齐中英文桌面构建说明

---

## 升级说明

### 如果你从 v0.7.0 升级

主要变化偏向工程与交付层，而不是用户工作流层：

- 当前文档与真实 remote API 表面更加一致
- 桌面构建与 sidecar 打包更稳定、更可预测
- 当前可靠性风险点上的测试与 CI 覆盖更强
- 凭据迁移与旧兼容边界更收敛
